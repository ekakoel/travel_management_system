# SPK WhatsApp Public Report

Status: retired
Updated: 2026-11-26

Transport Management/SPK runtime has been retired. Its web routes, controllers,
views, and frontend/backend assets have been removed. Public Transports
booking, order numbering, and the general WhatsApp API remain independent.

Database migrations, tables, columns, and existing SPK records are preserved
as historical data. This retirement does not drop or rebuild database objects.
